## Testing in Studio (MCP)
- **Before editing:** Azul must run (`Get-Process node`); stop any playtest (`get_studio_state`). The user often plays while Claude works.
- **Reach the live game:** the MCP can't require modules. On the Server: `workspace:SetAttribute("DevRequest", '["AddCoins", 50000]')`, then read `DevResult`. Commands (`Services/DevTools`): AddCoins, AddGems, AddRolls, AddRebirths, Snapshot, Restore, ShowOnLine (id, lineId), SetPurchased (id, bool), SetPurchasedList, BuildUpgrade, ResetPlot, GrantPass, GrantProduct, SpawnBox (rarity, n), Nuke, CreateThumb, GiveBrainrots. In game: `/dev <Command> <args>` in the chat, or the 🛠️ DEV menu (also on live servers, for developers only).
- **As a brand-new player:** in Edit, `workspace:SetAttribute("DevFreshStart", true)`, then Play (nothing loaded or saved, no passes, no leaderboard writes). **Clear it after** (`nil`), or every playtest starts fresh.
- **Tralalero's guide:** a fresh start plays it from the intro; `["Guide", "Box"]` through DevRequest (or `/dev Guide Box`) puts you on any step ("Intro" starts over, "Done" ends it; it saves).
- **The user's own profile** (`PlayerData_Studio`, Rebirth 5, ~25.8B Coins, every pass) saves: Snapshot before spending and Restore **before** stopping. Recovery from the DataStore's version history: docs/history.md ("Destructive tests").
- **Buy a button:** `PivotTo` the character onto it from the Client.
- **Keys:** `user_keyboard_input` reaches the game (E/F on prompts, Shift to sprint). ProximityPrompts only show while the camera follows the character: after camera tweaks set `CameraType = Custom` (in a `task.delay`) before pressing.
- **Clicks:** `user_mouse_input` takes GUI coordinates (screen y = GUI y + 58) and refuses spots under the Roblox chat window (top left): hide it on the Client (`TextChatService.ChatWindowConfiguration.Enabled = false`, and `ChatInputBarConfiguration`). A LocalScript the MCP creates with `Source` set runs with full rights (to require UI modules).
- **Screenshots:** one at a time, only when the look matters, only while Studio is rendering (not minimized: check `IsIconic` from PowerShell; `ShowWindow(h, 9)` restores, `6` minimizes back), or the call hangs. Pin the camera with `RunService:BindToRenderStep("ShotCam", Enum.RenderPriority.Last.Value, fn)` (Scriptable + CFrame), then unbind. Set `AlwaysOnTop = false` on BillboardGuis first (captures skip them). Prefer data probes (sample every 0.1 s). `execute_luau` resets the camera type after a call that changes it: start camera moves with `task.delay`.
- `get_console_output` is often empty; probe with `execute_luau`. FPS reads ~15 while Studio isn't focused. "Infinite yield on Plot*:WaitForChild("CashPad")" at start is harmless (streaming).

## Known quirks
- **Azul** (Studio-first): on (re)start it rewrites `sync/` from Studio, so commit first, and check `git status` right after (an Azul restart once pulled an older unsaved place and reverted 6 files: ask the user to save the place). It can die silently. It only updates scripts that already exist in Studio: a new file needs `python tools/studio_upsert.py --since <commit>` and the user pasting `tools/AddNewScripts.luau` into the Command Bar once (or the MCP push trick in docs/history.md, "Azul can die silently"). Never `git stash`/`checkout` while it runs (it pushes the disk into Studio).
- **Luau's 200-locals limit:** `TycoonManager` is at it and `ProductionVisuals` at 196 (top-level locals; "Out of local registers" breaks the script, and the type check doesn't catch it). Add no top-level locals there: new builders go in modules (`StationBuilder`, `RoomUpgradeBuilder`...), new constants in tables.
- **Type-check:** `sh tools/typecheck.sh` must print only "typecheck done".
- **Push** from PowerShell (Git Bash's push may fail auth).
- **Lives in the place file** (the user must save the place): the MaterialVariants CartoonGrass, PlushKnit, PlayDough, VinylGloss (recreate with `tools/SetupMaterials.luau` in Edit). `ServerStorage.Assets` is empty.
- **Characters spawn only after the world is built** (`Main.server`); builders that run over several frames call `WorkBudget.Step()` only where yielding is safe.
- **Cloud sessions** (no MCP, no Azul): push, plus the upsert script for new files; Linux luau-lsp for the type check (`LUAU_LSP`, `LUAU_DEFS`); geometry checks with `tools/lab` (docs/reference.md).
